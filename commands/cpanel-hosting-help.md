# cPanel Hosting Deploy Help

Show the user this command reference:

- **/cpanel** — main menu.
- **/cpanel-hosting-help** — complete command reference.
- **/cpanel-hosting-config** — manage connections and mappings, including renaming Default.
- **/cpanel-hosting-connections** — workspace onboarding and mapping.
- **/cpanel-local-status** — local deployment status: NEW, CHANGED, UNCHANGED, DELETED.
- **/cpanel-local-deploy** — safe incremental local-to-hosting deploy.
- **/cpanel-local-upload** — explicit full local-to-hosting overwrite/add operation.
- **/cpanel-remote-status** — detect REMOTE NEW, REMOTE CHANGED, REMOTE DELETED, and conflicts.
- **/cpanel-remote-sync** — explicitly sync selected remote changes to local.
- **/cpanel-remote-download** — explicit hosting-to-local download.

Never expose API tokens.
