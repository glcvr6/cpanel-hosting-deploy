# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful, and technically constructive community. Participants are expected to communicate professionally and to focus criticism on ideas, implementations, and evidence rather than people.

## Expected behavior

- Be respectful and constructive.
- Assume good faith while verifying technical claims.
- Welcome newcomers and questions.
- Share reproducible evidence when reporting technical problems.
- Protect private information, credentials, and customer data.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, deliberate exposure of secrets, malicious code submissions, or other abusive conduct is not acceptable.

## Enforcement

Project maintainers may edit, remove, or close content that violates this code of conduct and may restrict participation where necessary to protect the community.

For sensitive concerns, use the security/contact route described in `SECURITY.md` rather than posting private information publicly.
