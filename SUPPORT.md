## Documentation first

## Questions and bugs

Use GitHub Issues for reproducible bugs and feature requests. Please include enough sanitized technical detail to reproduce the problem.

Do not post API tokens, passwords, cookies, private customer data, or unredacted production logs.

## Security issues

For vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
