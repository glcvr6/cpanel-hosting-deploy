# cPanel Connections

Use this skill for `/cpanel-hosting-connections`.

First determine workspace state:
1. New/empty local folder — choose remote folders and download them locally.
2. Existing local project — map local folders to remote folders without automatic download.
3. Existing configuration — offer configuration changes.

Users have full freedom to choose remote folders. Do not hardcode public_html or restrict folders. Never print or expose API tokens.
