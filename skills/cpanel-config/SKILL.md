# cPanel Configuration

Use this skill for `/cpanel-hosting-config`.

Allow the user to add, edit, rename, and remove connections; enable/disable mappings; add/edit/remove mappings; and select any remote folder intentionally chosen by the user.

The Default connection can be renamed. Do not hardcode or restrict remote folder names.
Credentials must be stored securely and never printed, logged, or returned.
